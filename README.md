# allesausliebe · Website-Redesign

Liebevoller Redesign-Entwurf für [allesausliebe.de](https://www.allesausliebe.de/) –
handgemachte Schultüten, Geschwistertüten, Kissen & Babyglück von Inka Pauls
aus Stockelsdorf.

## Konzept

- **Design-Vorbild:** [persona-detstvo.ru](https://persona-detstvo.ru) (preisgekröntes,
  weiches und verspieltes Kinder-Design) – übertragen auf die Produktwelt von
  allesausliebe: warme Farben, runde Formen, liebevolle Illustrationen.
- **Zielgruppe:** Mütter, die zur Einschulung eine handgemachte, zum Ranzen
  passende Schultüte suchen.
- **Farbpalette:** Rosé `#E38AA0` · Creme `#FDF8F2` · Salbei `#A8C3A0` ·
  Apricot `#F2B880` · Sonnengelb `#F6CE6B`.
- **Schriften:** Fredoka (Überschriften), Nunito (Fließtext), Caveat (handschriftliche Akzente).

## Struktur

| Datei | Inhalt |
|---|---|
| `index.html` | One-Pager: Hero, Herzstücke (Kategorien), „So entsteht’s“, Kuschelkissen-Story, Instagram-Galerie, Stimmen, Über Inka, FAQ, Kontakt |
| `css/style.css` | Komplettes Styling inkl. Responsive & Reduced-Motion |
| `js/main.js` | Mobiles Menü, Scroll-Reveal, FAQ-Accordion |
| `impressum.html` / `datenschutz.html` | Platzhalter – vor Veröffentlichung mit echten Angaben füllen |

## Lokal ansehen

Einfach `index.html` im Browser öffnen – keine Build-Tools nötig.

## Vor dem Livegang

- Echte Produktfotos in Hero, Galerie & Kategorien einsetzen (Platzhalter sind Illustrationen).
- Impressum & Datenschutz von der Original-Website übernehmen.
