# SCM Creatives: Briefing (Antworten vom 21.10.2026)

| Thema | Entscheidung |
|---|---|
| KI | **100 % ohne KI** (Videos von SCM). KI-Bilder nur als Platzhalter beim Website-Bau, SCM liefert echte Bilder nach |
| Skript | Skript-Aufbau erklären, **keine echten Kundenskripte** zeigen |
| Preise | **Pakete ohne Preise** |
| Pakete | 3 Pakete: **4 / 8 / 12 Videos pro Monat** |
| Einstieg | **3 kostenlose Testvideos** („wie es werden kann“), danach Vertragsabschluss |
| Leistungen | Skript, Dreh, Schnitt + Posting & Community, Werbeanzeigen, Recruiting-Videos, Fotos / Imagefilm |
| Anfrage | Quiz + WhatsApp + Anruf |
| Anfragen landen | **nur per E-Mail** (kein CRM) |
| Design | **Dunkel + Weiß + Rot**, Drehbuch-Signatur |
| Umfang | Vollausbau mehrseitig, zusätzlich **Vision** und **Kontakt**. Branchen in alle Richtungen offen, die 4 Branchen (Gastro, Immobilien, Handwerk, Unternehmen) sind Referenzbeispiele |
| Higgsfield | KI-Platzhalterbilder erlaubt, max. **50 Credits** |
| Impressum, Team, Kontaktnummern | Platzhalter, kommen später |
| Standort | **Kiel und Lübecker Bucht**, kein Kundenbüro, SCM kommt zu den Kunden in Laden / Unternehmen |
| Referenzen | Alle freigegeben: BS Immobiliengruppe, Maler Rohwer, Jan & Hein & Klaas & Pit, Das kleine Steakhouse, Kletterwald Travemünde, **plus Weinbar „Die Drei“ (Kiel)** |
| Videos | SCM schickt Links zu weiteren Reels |
| Logo | Vektordatei kommt von SCM |
| Domain | **scm-creatives.de**, Registrar später entscheiden |
| Hosting | **eigenes SCM-Konto** bei Vercel (Pro) |
| Rahmen | Eigenes / Partner-Projekt, keine Deadline genannt |

## Offen / kommt von SCM
- Impressum-Daten, Bedeutung „SCM“, Team (Namen, Rollen, Fotos, Gründungsjahr)
- Telefon / WhatsApp, E-Mail für Anfragen
- Logo als Vektor (Normalversion)
- Links zu weiteren Reels, später Original-Exporte (1080×1920, lizenzfreie Musik)
- Instagram-Name der Weinbar „Die Drei“ (online nicht eindeutig auffindbar)
- Echte Fotos als Ersatz für die KI-Platzhalter
